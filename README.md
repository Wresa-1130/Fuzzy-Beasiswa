# Fuzzy-Beasiswa
Sistem Pendukung Keputusan (SPK) berbasis Logika Fuzzy untuk membantu seleksi penerima beasiswa secara objektif dan efisien. Sistem mengevaluasi berbagai kriteria seperti nilai akademik, pendapatan orang tua, tanggungan keluarga, dan prestasi guna menghasilkan rekomendasi kelayakan beasiswa.

## Menjalankan

```bash
pip install -r requirements.txt
streamlit run app.py       # web
python test_fuzzy.py       # uji otomatis
```
